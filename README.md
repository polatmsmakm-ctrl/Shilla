# الشلّة

رسائل وملفات ضخمة بين أصدقائك. يوزر ثابت بدون أكواد وبدون سيرفر تنشره.

- **الدردشة**: عبر سيرفرات MQTT عامة مجانية، وكل الرسائل مشفّرة (AES-GCM).
- **الملفات**: مباشرة من جوال لجوال (WebRTC) عبر 4 قنوات متوازية، تُقرأ وتُكتب على القرص قطعة قطعة.
- **الاستكمال**: يحفظ علامة تقدّم، ولو انقطع الاتصال يعيد المحاولة تلقائياً ويكمل من نفس المكان.
- **البناء**: Actions يبني `Shilla.ipa` وينشره في Releases.

## ملاحظات
- كل الأصدقاء لازم يثبتون نفس البناء (نفس المفاتيح في `Secrets.swift`).
- المفاتيح داخل الكود، فالأفضل تخلي الريبو Private.
- النقل المباشر يحتاج الطرفين متصلين وقت الإرسال.
